# 完整需求草案｜V1.0

**阶段：需求确认。此文把已明确的目标与仍待选择的细则分开；不等于已发布施工合同。**

## 一、家庭成长制度

### 任务模板库
- 可无限添加模板，不受原 77 项清单限制。模板按生活卫生、阅读学习、运动、家务、自主管理、情绪社交和成长挑战等分类。
- 参考优质纸质亲子打卡表、成长积分表以及专业儿童成长建议来补充模板；必须经过复核再引入。不得未经授权照搬销售产品的整体文案与图片。
- 每个模板至少能定义：年龄/能力建议、完成标准、分类、可选难度、次数/时长目标、周期、重复上限、可能的积分与审核方式。
- 家长或孩子从模板库挑选加入个人任务计划；孩子不能通过自行加任务/提高分值获得无约束积分。
- 基本家庭规则与任务分开：尊重、安全、诚实等不可作为积分可以购买的豁免权。

### 计划、完成与审核
- 支持每日、每周、指定日期的任务及适龄成长挑战；允许休息、请假、生病或临时调整计划。
- 儿童自主查看、申请完成、查看待审/通过/退回结果。
- 家长端支持添加/修改/停用计划、退回、批量审核、补记和纠正。
- 低风险可授权自动确认，重要和异常事项人工确认；两位家长同时操作不能重复发奖。
- 记录习惯养成后的变化，支持任务难度升级、奖励逐步淡出以及从日常任务栏“毕业”。

### 积分与完成率
- 游戏**原有**金币、经验、道具及升级规则优先保留；现实任务批准后通过受控桥接触发奖励，不额外造出与游戏冲突的金币系统。
- 现实奖励另有家长定义的兑换、审批与兑现状态；必要时保留可审计的映射及流水。
- **完成率**：基于已核准且当前应做的任务计划计算，不能让孩子临时删掉未完成事项提高百分比。
- **有效完成量**：完成实例数与难度/时长/质量等合理权重可分开统计；10/10 与 100/100 同为 100% 时，有效贡献可不同。
- 必须设置重复计分、细碎拆分、过量安排的保护；不以“任务越多越好”压迫儿童，允许有弹性的日目标和完成率分母。
- 适龄活动强调主动、参与与个人进步，不按姐弟之间的排名施压。

## 二、完整宠物游戏（先找成熟主体）

**基础体验必须：** 可爱且互动自然的宠物、领养/命名、可见成长、富有变化的动画或反应、原生游戏奖励/商店/背包、足够保持兴趣的真实游戏内容。

**重要方向，优先沿用原游戏：** 宠物性格与喜好、成长形态或进化、收集与换装、小屋及家具、地图和探索、纪念收藏、特殊故事和节日事件。

**儿童协作：** 两名孩子独立存档与金币，可有合作任务、共同建造或共同解锁，但不强行开发复杂多人在线架构。

**不采用的激励：** 强迫连续签到、宠物因失误死亡或严重生病、基础喂养持续扣掉现实奖励积分、随机付费抽卡、无限刷奖励或需长期在线的设计。

## 三、游戏与现实任务连接

### 最小闭环
1. 儿童在**宠物游戏内**查看现实任务。
2. 现实中完成，在游戏里点击完成并申请。
3. 家长手机审批或事先授权的自动确认。
4. 奖励事件经过唯一性与权限检查，进入成熟游戏的原生金币/经验/道具系统。
5. 儿童看到宠物成长、活动解锁或游戏内物品变化，家长看到可靠记录。

### 异常必须明确处理
- 重复点击、重复网络请求、双家长并行审核、离线重试不得重复奖励。
- 可以更正误审及误发分，保留历史证据，不能静默改余额。
- 每名儿童只影响自己的游戏存档，合作奖励范围应明确。
- 游戏更新、迁移、存档恢复时，不能导致任务历史或奖励错乱。

## 四、游戏内容与设备控制

**已经确认 C 方案，两个方向都要：**
- 游戏内部：按当天已核准的指定任务和有效努力分阶段解锁照料、家园、冒险等互动；任务入口永远可用。
- 平板系统：完成约定任务后能临时开放其他指定娱乐 App；家长可以调节与放行，不影响联系和学习工具。

**待验证：** 华为 Pad 实际型号/系统权限、系统级娱乐 App 管控 API、家长手机与平板之间的安全同步方式。普通网页本身不具备直接控制其他 App 的权限，不能把假设写成已完成。

## 五、儿童端与家长端

**儿童端：** 华为 Pad 优先，游戏画面主体明确，图标/中文大且可读，角色切换不串档，查看任务和交互轻松。游戏互动时长可管理，避免无限滚动/重复小游戏。

**家长端：** 两台手机的家长共同管理（权限可设），待办与审批及时、批量操作简单；能设奖励价格、查看余额、任务完成率、有效量、运动进步与习惯变化。支持追踪与备份。

## 六、安全和长期运行

- 私人家庭数据不进入 GitHub 公开仓库；收集最少必要信息。
- 游戏的代码、模型、字体、UI、宠物图片、动画、音频逐项核验许可，不能把商业游戏宣传素材当可复用资源。
- 使用成熟开源项目时，保留可升级性，避免大面积修改核心；如无法兼容需要清楚解释净收益。
- 需要验收真实操作、同步、恢复、内容安全、使用时长与家长实际负担。

## 七、当前仍属建议而非最终固定的数值

每天任务数量建议先从 3～5 项重要项目起步；积分按游戏现有奖励规模调节；宠物基础照料应免费；完成率与工作量奖励的权重、上限及连续习惯奖励尚待家庭试用后调校。**不能现在就把草案数值写死为引擎代码。**
