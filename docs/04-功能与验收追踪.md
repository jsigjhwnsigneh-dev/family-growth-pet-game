# 功能与验收追踪｜V1.0 候选

所有条目当前状态均为**未开发 / 未验收**。“必需”指产品目标；“重要”指优先争取且可结合成熟游戏实际能力调整；“扩展”不阻断初始可用版本；“技术风险”需要专项证据。

| ID | 能力 | 级别 | 最低可核查验收 |
|---|---|---|---|
| REQ-01 | 两名孩子独立账户/存档/成长数据 | 必需 | 切换角色不串任务、金币、宠物 |
| REQ-02 | 两位家长管理及权限 | 必需 | 两手机查看一致，审批不冲突 |
| REQ-03 | 不受 77 项限制的可扩展任务模板库 | 必需 | 可新建/分类/搜索/复用模板 |
| REQ-04 | 自定义任务目标、难度、周期和适用人 | 必需 | 多种频率和标准均可运行 |
| REQ-05 | 家长/孩子从任务库加入任务栏 | 必需 | 孩子可申请加入，计分规则受控 |
| REQ-06 | 休息、暂停、异常日期 | 必需 | 不产生不公平失败记录 |
| REQ-07 | 孩子自主打卡与申请确认 | 必需 | 待审/批准/退回状态清楚 |
| REQ-08 | 手机审批、批量确认和补记 | 必需 | 核实流程可操作、记录可靠 |
| REQ-09 | 低风险任务的受控自动确认 | 重要 | 可配置允许范围，不越权 |
| REQ-10 | 审核、积分和奖励的可追溯、防重复 | 必需 | 双审/重复提交/断网重试不多发 |
| REQ-11 | 现实任务映射成熟游戏原生金币/经验/物品 | 必需 | 完成一项任务，游戏正确奖励一次 |
| REQ-12 | 现实奖品兑换、审批和兑现 | 必需 | 积分消费与兑现记录一致 |
| REQ-13 | 完成数量、完成率、有效任务量及个人进步 | 必需 | 可分开查看，分母不可随意作弊 |
| REQ-14 | 任务数量、难度与奖励匹配，防刷分 | 必需 | 10/10与100/100适当区分，恶意拆单无效 |
| REQ-15 | 习惯提升与任务毕业 | 重要 | 可以逐渐减少奖励，保留成长记录 |
| REQ-16 | 跳绳、跑步等运动记录 | 必需 | 能看到目标、完成和个人进步 |
| REQ-17 | 已成熟可玩的宠物游戏作为主体 | 必需 | 原游戏运行并有实际可玩内容 |
| REQ-18 | 宠物领养、命名、自然动画和互动 | 必需 | 儿童能独立操作互动 |
| REQ-19 | 宠物成长、升级与现实任务关联 | 必需 | 游戏中的变化可见、可核查 |
| REQ-20 | 原生商店/背包/长期养成内容 | 必需 | 保留成熟游戏内已有能力 |
| REQ-21 | 性格、进化、宠物收集和换装 | 重要 | 优先保留原游戏，符合年龄 |
| REQ-22 | 家园、布置、探索地图或故事 | 重要 | 原生能力能持续玩，不强制自建 |
| REQ-23 | 手足合作、共同奖励或家园互动 | 重要 | 合作成果可见且不串个人账 |
| REQ-24 | 游戏内现实任务入口 | 必需 | 儿童不用退出游戏找另一套任务软件 |
| REQ-25 | 按当日真实完成进度开放游戏内容 | 必需 | 仅历史余额不能绕过目标 |
| REQ-26 | 按任务进度控制平板其他娱乐 App | 最终必需·技术风险 | 真机证据验证，必要工具不受影响 |
| REQ-27 | 临时放行、学习与安全工具保护 | 必需 | 家长随时可调整且留日志 |
| REQ-28 | 平板儿童中文交互与适龄可读性 | 必需 | 两名孩子能自己找任务、打卡和领奖 |
| REQ-29 | 双家长手机同步及成长视图 | 必需 | 实际跨设备同步可靠 |
| REQ-30 | 游戏时长管理与健康激励 | 必需 | 不依赖逼迫宠物存活或无限刷内容 |
| REQ-31 | 备份、恢复和儿童数据保护 | 必需 | 可恢复真实存档/任务与积分记录 |
| REQ-32 | 源码、形象、图片、音乐许可核查 | 必需 | 有可追溯许可证与授权结论 |
| REQ-33 | 儿童手表上的简化宠物/提醒 | 扩展 | 真实型号开发权限验证 |
| REQ-34 | 儿童手表运动数据自动联动 | 扩展 | 有可用接口与授权实证 |
| REQ-35 | 随机故事、自主宠物动作、节日内容 | 扩展 | 不影响核心任务闭环 |
| REQ-36 | 两名儿童实际家庭试用 | 必需 | 能持续使用，家长负担合理 |
