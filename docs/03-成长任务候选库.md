# 成长任务候选库｜持续扩展

**初始内容：70 个候选成长行为 + 7 条家庭基本规则，合计 77 个条目。77 不是上限，也不是每天应完成的任务数量。**

本库主要给家长与孩子提供可勾选的“任务素材”。每个模板进入正式计划前，应设置完成标准、适龄难度、周期和合理次数；家长把关积分与目标，鼓励孩子参与选择。

## 模板库继续扩充（待调研，不代表已核实来源）

后续重点调研网上销售的纸质家庭积分表/打勾表及免费亲子习惯清单，借鉴其**任务分类与能力覆盖**，但不得未经许可搬运设计、素材或完整商用内容。优先补充：饮食与卫生细项、独立出行安全、环保与自然、艺术创作、情绪调节、公共场合礼仪、财商基础、数字设备习惯、合作与服务、生活小技能。

## 任务计划与积分保护

- 模板库可以很多，**每日任务栏应适龄、可执行**；先选少量重要任务，后续按成长逐渐调整。
- 孩子可自行选择并提交加入申请；**家长对任务量、难度、积分与频率负责确认**。
- 任务可每日/每周/指定时段出现；相同动作拆成多条等价任务，不应重复获得奖励。
- 分开记录 **有效完成数量、计划完成率、有效任务量/难度权重、主动性进步**。
- 10/10 与 100/100 的完成率均为100%，但真实有效工作量可能不同。比较时必须考虑周期、任务质量、难度与安全，**不鼓励孩子为了100件任务牺牲休息和玩耍**。
- 奖励计算方法尚未定稿，待与成熟宠物游戏的原生金币/经验系统一起校准。
