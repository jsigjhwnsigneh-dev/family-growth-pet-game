# 成熟宠物游戏底座｜候选评估与决策模板

## 优先找什么

首先寻找一款**本身已经完整可玩、有成熟宠物养成和足够游戏内容**的项目，并且能用最小扩展增加现实任务/家长审批/奖励。若现成项目已经原生提供任务或成长功能，更值得优先验证，但不能仅看功能名称。

**不是先选引擎，也不是先找若干贴图、小游戏，随后自己拼一个游戏。**

## 一票否决或重大风险

- 不能运行，或仅有演示、宣传截图、半成品。
- 代码可见但未许可复用；宠物形象、美术、动画、音乐来源不明。
- 核心玩法、内容或付费机制对低龄儿童不适合且难以移除。
- 没有合理外部奖励接入点，必须把原游戏大部分功能重写。
- 无法适配目标华为平板，或者长期不可维护。
- 存档与家庭数据不可恢复、权限或儿童隐私无保障。

## 每个候选应回答

| 维度 | 需要的证据 |
|---|---|
| 完整度 | 可运行版本、真实画面、玩法覆盖与内容量 |
| 宠物体验 | 动画、触摸互动、养育、成长进化、故事 |
| 长期体验 | 家园、道具、收集、探索、合理更新节奏 |
| 儿童友好性 | 中文、触屏、小字问题、广告与外部社交 |
| 外部接入 | 能否通过接口/插件/小幅修改添加现实任务与奖励 |
| 游戏经济 | 金币/经验/物品能否原样复用，安全发放一次 |
| 存档与多用户 | 两名孩子独立存档、家长审批记录、备份 |
| 授权 | 代码、模型、动画、美术、声音逐项清楚 |
| 设备兼容 | 平板性能、横屏与控制技术实证 |
| 长期成本 | 上游维护、改动规模、升级冲突与素材制作量 |

## 初选矩阵

每项功能标记：**原生完整 / 配置可用 / 接口接入 / 修改源码 / 不支持 / 尚未验证**，附上版本、源码路径、实测照片/视频或正式说明。不能把作者的未来计划当作已实现。

## 最终提交给用户的结论

- 真实可运行的候选及其版本/来源；
- 完整保留多少游戏功能、需要重做多少；
- 影响最终产品目标的主要缺口；
- 改造量、长期维护成本及版权条件；
- 华为 Pad 与系统级 App 限制的实证结果；
- 候选对比和选型建议，明确哪些判断未经验证。

## 既有调研线索（非选型结论）

此前讨论过 Joon（商业参考）、Krepagotchi、Tamagochi 开源游戏、Pet Grow Up、VPet、Pointsy 与 OpenChore。它们的游戏完整度、可扩展性、授权边界与可直接复用比例仍需**重新按同一标准现场核验**，当前没有指定唯一游戏底座。
