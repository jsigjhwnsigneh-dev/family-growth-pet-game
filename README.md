# 家庭成长游戏（Family Growth Pet Game）

**当前阶段：3/5 成熟宠物游戏调查与选型｜首轮源码筛选已记录｜游戏底座未选｜未授权正式开发。**

本项目面向低龄儿童家庭：以一款**现成、成熟、可合法改造的完整宠物养成游戏**为产品主体，在其中扩展现实成长任务、家长审批、积分奖励与游戏解锁。孩子通过喜欢的游戏逐渐养成生活、阅读学习、身体锻炼和自主做事的习惯。

## 核心路线

- **先确定需求 → 列出可验收能力 → 寻找成熟项目 → 最小必要补缺 → 整合成品。**
- **产品采用 B 方案**：宠物世界是主体；现实成长制度寄生为游戏扩展。原游戏的动画、美术、宠物、家园、商店与玩法尽量完整保留，不以自建游戏为默认方案。
- 儿童在平板中看任务并提交；家长在手机上审批；审批成果驱动**原游戏的金币、经验、物品和内容解锁**。
- 支持两名儿童独立存档及合作目标，允许家长或孩子从不断扩大的任务模板库选择计划任务。
- 评价同时关注**有效完成量、任务完成率、自主性和个人进步**，不以堆积简单任务刷分。
- 需求包含**游戏内部阶段解锁**和**平板其他娱乐应用的限制**；后者尚需对华为设备实证，不能预先承诺技术实现。
- 儿童手表是未来扩展，不阻断基础产品推进。

## 当前调查结论

**Tamaweb值得优先继续核验，但资产授权与家庭接入尚未过关；Bunbons作为养成与探索的比较候选；Tamagochi / Mori为较小规模技术备选，不能自动等同成熟完整世界。** 本轮没有选定游戏、发布游戏或开始产品编码。试玩尝试不等于已经通过，来源与证据限制见下方记录。

## 现实成长与游戏的完整闭环

儿童在宠物游戏内查看任务 → 现实中完成并申请 → 家长手机批准（或事先授权自动确认） → **仅发放一次**游戏原生奖励 → 宠物出现可见变化 → 家长查看成长记录与进度。

## 隐私及开源边界

这是一个**公开仓库**。不得提交真实儿童姓名、照片、语音、定位、学校及家庭实际使用记录，不得提交密码和密钥。源代码许可与宠物形象、字体、音乐等素材许可必须分别核实。尚未选定游戏底座和最终许可证，**本仓库公开可见不等于允许自由复制其中的所有内容**。
